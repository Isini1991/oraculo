# ORÁCULO — a signal from the underground

Private speculative website concept for Esi to present to Nico Cabañas. Not published or claimed as the official label website.

## Creative direction
An independent record label should feel like a record, not a software company. Build a tactile black / warm paper / signal red editorial experience: oversize condensed typography, fine technical rules, actual sleeve art, generous whitespace, no rounded SaaS cards or generic gradients.

Hero: a custom Three.js vinyl sculpture, procedural radial-groove shader, red printed centre label, polished edge, elliptical orbital markings, subtle dust. Pointer-driven camera and draggable disc. Scroll tips and recedes the object; native document scroll is never hijacked. Actual release sleeves and editorial story ground the spectacle in the label.

## Content sources
- https://oraculorecords.bandcamp.com/ — label description, release names, artists and covers
- https://www.keyimagazine.com/2025/05/24/estado-de-bienestar-oraculo-records/ — Nico Cabañas and Estado de Bienestar feature
- supplied label Instagram, Facebook, Discogs and Ombra Instagram for outbound links
No fabricated catalog numbers, prices, current events, availability or artist biographies.

## Structure
Navigation → immersive WebGL hero → six selected releases + search → oversized typographic manifesto → Estado de Bienestar editorial feature → interactive artist index → Ombra connection → high-impact footer.

## Interactions
Accessible mobile menu, filter/search, release detail dialog with genuine outbound purchase/listen links, optional official Bandcamp embed only after request, disc pointer manipulation, keyboard control, animation pause, source credits dialog. Modal focus trapping, escape, restoration. No nonfunctional newsletter/contact forms.

## Quality budget
Self-contained static page + vendored classic Three.js + local fonts/assets; direct file:// and localhost support. No build step, credentials, paid services, analytics or automatic external media requests. Native scroll, reduced motion, 375/768/1024/1440 responsiveness, DPR <=1.5; stop rendering when hero offscreen or tab hidden. Render fallback when WebGL unavailable. __oraculo.getState / force test hooks, actual Chrome verification and screenshots.

## Handoff
Source folder, launchable index.html, ZIP of runtime files, provenance notes and verification report. Preview remains private unless separately published with label approval and artwork permissions.
